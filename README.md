# Project Setup Guide
### Prerequisites

Make sure you have the following installed:

- Node.js and npm — for the frontend
- Python 3.x — for the backend
- A database — configured according to your project requirements
- Git — for version control

### Cloning the Repository
```bash
git clone <repository-url>
cd <project-directory>
```

### Frontend Setup

Navigate to the frontend directory and install dependencies:
```bash
cd frontend
npm install
```


Start the development server:
```bash
npm run dev
```


The frontend will run at the URL displayed in your terminal, commonly http://localhost:5173 for Vite.

### Backend setup
Navigate to the backend directory:
```bash
cd backend
```

Create and activate a virtual environment:
```bash
python -m venv venv
source venv/bin/activate
```

Install dependencies:
```bash
pip install -r requirements.txt
```

Configure your environment variables:  
Create a .env file in the root directory and configure the required variables.

Example:
```text
DATABASE_URL=your_database_connection_string
```

Start the backend server:
```bash
uvicorn main:app --reload
```

The backend API will be available at http://localhost:8000.

### Running database migrations
Ensure your database is running and the database connection settings are configured before running migrations.

Generate a migration after making model changes:

```bash
alembic revision --autogenerate -m "describe your changes"
```

Apply pending migrations:
```bash
alembic upgrade head
```

To check the current migration version:
```bash
alembic current
```

Note: Review autogenerated migration files before applying them, especially when modifying or dropping existing columns or tables.

### API documentation
Start the backend server and open the interactive API documentation:

Swagger UI: http://localhost:8000/docs
